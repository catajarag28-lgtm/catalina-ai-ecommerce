# Catalina Jaramillo — portafolio comercial

Sitio React/Vite en GitHub Pages y Carolina en Cloudflare Worker + D1 + OpenRouter. La web presenta estrategia, ventas, CX, growth, ecommerce, operaciones y sistemas con IA desde los dolores del empresario. Carolina es la demostración conversacional del producto.

Desarrollo: `npm ci`, `npm run dev`, `npx wrangler dev`. Pruebas: `node --test tests/*.test.mjs`; build: `npm run build`. Configuración e integraciones: [docs/DEPLOY_CAROLINA.md](docs/DEPLOY_CAROLINA.md). Constitución: [docs/CAROLINA_CONSTITUTION.md](docs/CAROLINA_CONSTITUTION.md).
